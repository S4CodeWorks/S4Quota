# Application screenshots

This directory is reserved for screenshots captured from the running S4Quota
application. No real application screenshots are versioned yet.

When available, add these captures here:

- `main-dark.png`
- `main-light.png`
- `compact-dark.png`
- `compact-light.png`

Capture the application itself and note the tested Windows display scale when
it affects legibility. Do not use Impeccable comps or generated mockups as
screenshots of the shipped UI.
